网页授权登录 推荐

无需抓包、无需密码。方式一全自动（需本机助手）；方式二手动粘贴回调链接，任何设备都能用。

方式一：本机助手（全自动） 下载助手 start_auth.bat

方式二：手动粘贴回调链接

  1. 点此打开 Trae 授权页（新窗口）并登录
  2. 登录后浏览器会跳到 127.0.0.1:18080/authorize?... 并提示无法访问 —— 这是正常的，凭证就在地址栏里
  3. 复制地址栏完整链接粘贴到下面，点「导入」

JSON 批量导入

支持对象或数组。字段：token/accessToken、refresh_token、user_id、label、enabled

账号密码登录导入 实验性

端点未公开文档化，可用环境变量 TRAE_LOGIN_PATH 适配；失败时建议改用 JSON 导入 refresh_token。
